# 🎓 LearnDash Academy - Maîtrise de la Conception Angular

**Objectif du Projet :**
Ce projet a été conçu pour perfectionner la maîtrise de la conception de vues sous **Angular**. L'accent est mis sur la compréhension et la manipulation de la structure modulaire d'Angular, en travaillant de manière isolée sur chaque élément d'un composant :
*   **Logic (.ts)** : Gestion de la logique et du cycle de vie.
*   **Template (.html)** : Structure sémantique de la vue.
*   **Style (.css)** : Mise en forme précise et isolation des styles.
*   **Test (.spec.ts)** : Validation du bon fonctionnement des composants.

---

## ✨ Fonctionnalités Principales

*   **Catalogue de Cours** : Exploration facilitée des différentes formations disponibles.
*   **Articles & Détails** : Système de news et de détails d'articles par catégories.
*   **Espace Membre** : Gestion du compte utilisateur simplifiée.
*   **Design Premium** : Interface moderne avec des animations fluides et un layout optimisé pour mobile.
*   **Responsive Design** : Expérience adaptée sur PC, Tablette et Mobile.

---

## 🛠️ Stack Technique

*   **Framework** : [Angular 19](https://angular.dev/)
*   **Stylisation** : [Tailwind CSS](https://tailwindcss.com/)
*   **Icônes** : FontAwesome 6
*   **Architecture** : Components Standalone & Signaux (Signals)

## 🚀 Installation Rapide

### 1. Prérequis
*   **Node.js** (v20 ou supérieure recommandé)
*   Un gestionnaire de paquets au choix : **npm**, **yarn**, ou **pnpm**.

### 2. Installation
Utilisez votre gestionnaire de paquets favori (**npm** est recommandé) pour installer les dépendances :
```bash
npm install
# OU
yarn install
# OU
pnpm install
```

### 3. Lancement
```bash
npm start
# OU
yarn start
# OU
pnpm start
```
Accédez à l'application sur `http://localhost:4200`.
